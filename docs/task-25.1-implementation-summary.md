### Build Steps Implemented

The master build script executes these steps in sequence:

#### Step 0: Setup Python Virtual Environment
- Verifies Python 3.12+ availability
- Creates/activates venv at `PROJECT_ROOT/venv`
- Installs build dependencies: pyyaml, jinja2, requests, hypothesis, pytest
- **Requirement**: Python 3.12+ for build scripts

#### Step 1: Run kubespray-offline Asset Collection
- Executes `kubespray-offline/download-all.sh`
- Downloads K8s binaries, container images, packages, wheels
- Validates outputs directory structure
- **Requirements**: 1.1, 1.2, 1.3, 1.4, 1.7
- **Time**: 30-60 minutes
- **Skip option**: `--skip-download`

#### Step 2: Organize Assets for Zarf
- Runs `organize_assets_for_zarf.sh`
- Copies kubespray-offline outputs to `assets/` directory
- Structures assets by component type
- **Requirement**: 2.3
- **Time**: 2-5 minutes

#### Step 3: Collect Terraform Providers (OpenStack mode)
- Runs `mirror_terraform_providers.sh`
- Downloads Terraform providers for offline use
- Only executes if `--openstack` flag set
- **Requirements**: 1.5, 1.8
- **Time**: 5-10 minutes
- **Skip option**: `--skip-terraform`

#### Step 4: Validate Version Pinning
- Runs `version_validator.py`
- Scans configuration files for unpinned versions
- Fails build if "latest", "stable", or wildcards found
- **Requirements**: 10.1-10.7, 10.10
- **Time**: < 1 minute
- **Skip option**: `--skip-validation`

#### Step 5: Generate zarf.yaml and Create Package
- Runs `generate_zarf_yaml.py` to create package definition
- Runs `create_zarf_package.sh` to build package
- Produces `dist/zarf-package-openCenter-airgap-*.tar.zst`
- **Requirements**: 2.1, 2.3, 2.8, 2.9, 2.10
- **Time**: 10-30 minutes

#### Step 6: Verify SBOM Generation
- SBOM automatically generated by Zarf during package creation
- Runs `verify_sbom.py` to check completeness
- Ensures all components listed in SBOM
- **Requirements**: 2.4, 2.5, 10.9
- **Time**: < 1 minute

#### Step 7: Generate Checksums
- Runs `checksum_utils.py` to compute MD5 and SHA256
- Saves checksums to `<package>.checksums` file
- **Requirements**: 1.10, 2.6
- **Time**: 1-5 minutes

#### Step 8: Sign Package (Optional)
- Runs `sign_package.sh` if `COSIGN_KEY` environment variable set
- Creates detached signature with Cosign
- Gracefully skips if Cosign not available
- **Requirement**: 2.7
- **Time**: < 1 minute
- **Skip option**: `--skip-signing`

### Command-Line Options

```bash
--skip-download       Skip kubespray-offline asset download (use existing)
--skip-terraform      Skip Terraform provider collection
--skip-validation     Skip version validation (not recommended)
--skip-signing        Skip package signing (even if key available)
--openstack           Enable OpenStack mode (collect Terraform providers)
--help                Show help message
```

### Environment Variables

```bash
PYTHON_VERSION        Python version to use (default: 3.12)
COSIGN_KEY            Path to Cosign signing key (optional)
SKIP_ASSET_DOWNLOAD   Skip asset download if set to "true"
OPENSTACK_MODE        Enable OpenStack mode if set to "true"
```

### Output Artifacts

After successful build, these artifacts are created in `dist/`:

- `zarf-package-openCenter-airgap-amd64-<version>.tar.zst` - Main package
- `<package>.checksums` - MD5 and SHA256 checksums
- `<package>.sig` - Cosign signature (if signed)
- `package-inspection.txt` - Package contents listing
- `package-sbom.txt` - Software Bill of Materials
- `sbom-verification-report.txt` - SBOM completeness report

## Usage Examples

### Full build (first time)
```bash
# Clone kubespray-offline
git clone -b main https://github.com/tmurakam/kubespray-offline.git build/kubespray-offline

# Run full build
./scripts/build/build.sh
```

### Build for OpenStack
```bash
./scripts/build/build.sh --openstack
```

### Rebuild without re-downloading
```bash
./scripts/build/build.sh --skip-download
```

### Build with signing
```bash
# Generate key pair (first time)
cosign generate-key-pair

# Build and sign
COSIGN_KEY=cosign.key ./scripts/build/build.sh
```
