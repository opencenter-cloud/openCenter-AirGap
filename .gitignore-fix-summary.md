# .gitignore Fix Summary

## Problem
The `.gitignore` file had an overly broad pattern `/build/` that was ignoring the entire `build/` directory at the repository root. This caused `scripts/build/` to be ignored, preventing important build scripts from being tracked in git.

## Root Cause
The pattern `/build/` matches any directory named `build` at the root level, which includes:
- `/build/` (intended - build artifacts directory)
- `scripts/build/` (unintended - build scripts directory)

## Solution
Changed the `.gitignore` pattern from:
```
# Build artifacts
/build/
dist/
```

To:
```
# Build artifacts (ignore build output directory, not scripts/build/)
/build/kubespray-offline/
/build/*.tar.gz
/build/*.log
dist/
```

## Impact

### Now Tracked (Previously Ignored)
All files in `scripts/build/` can now be tracked:
- `build.sh` - Master build orchestration script
- `checksum_utils.py` - Checksum calculation utilities
- `generate_zarf_yaml.py` - Zarf package manifest generator
- `organize_assets_for_zarf.sh` - Asset organization script
- `validate_assets.py` - Asset validation script
- `version_validator.py` - Version pinning validator
- `verify_sbom.py` - SBOM verification script
- And 15+ other build scripts

### Still Ignored (As Intended)
Build artifacts remain ignored:
- `/build/kubespray-offline/` - kubespray-offline clone and outputs
- `/build/*.tar.gz` - Downloaded tarballs
- `/build/*.log` - Build logs
- `dist/` - Distribution packages

## Verification
```bash
# Verify scripts/build/ is NOT ignored
git check-ignore scripts/build/build.sh
# Exit code 1 = not ignored ✓

# Verify build artifacts ARE ignored
git check-ignore build/kubespray-offline
# Exit code 0 = ignored ✓
```
