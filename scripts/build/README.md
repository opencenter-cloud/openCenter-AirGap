# Build Scripts

This directory contains scripts for building the openCenter AirGap package.

## Master Build Script

**File**: `build.sh`

The master build script orchestrates the complete build process from asset collection to package signing.

### Prerequisites

- Python 3.12+ installed
- Podman or Docker installed
- Git installed
- Zarf CLI installed (https://docs.zarf.dev/getting-started/install/)
- 50GB+ free disk space
- Internet connectivity (build phase only)
- kubespray-offline cloned to `build/kubespray-offline/`

### Quick Start

```bash
# Clone kubespray-offline (first time only)
git clone -b main https://github.com/tmurakam/kubespray-offline.git build/kubespray-offline

# Run full build
./scripts/build/build.sh

# Build with OpenStack support
./scripts/build/build.sh --openstack

# Skip asset download (use existing)
./scripts/build/build.sh --skip-download
```

### Build Steps

The build script executes the following steps in order:

1. **Step 0**: Setup Python Virtual Environment
   - Verifies Python 3.12+ is available
   - Creates/activates venv at `PROJECT_ROOT/venv`
   - Installs build dependencies (pyyaml, jinja2, requests, hypothesis, pytest)

2. **Step 1**: Run kubespray-offline Asset Collection
   - Executes `kubespray-offline/download-all.sh`
   - Downloads K8s binaries, container images, apt packages, Python wheels
   - Takes 30-60 minutes depending on network speed
   - Skip with `--skip-download` if outputs already exist

3. **Step 2**: Organize Assets for Zarf
   - Runs `organize_assets_for_zarf.sh`
   - Copies kubespray-offline outputs to `assets/` directory
   - Structures assets by component type

4. **Step 3**: Collect Terraform Providers (OpenStack mode only)
   - Runs `mirror_terraform_providers.sh`
   - Downloads Terraform providers for offline use
   - Only runs if `--openstack` flag is set
   - Skip with `--skip-terraform`

5. **Step 4**: Validate Version Pinning
   - Runs `version_validator.py`
   - Checks all configuration files for unpinned versions
   - Fails build if "latest", "stable", or wildcards found
   - Skip with `--skip-validation`

6. **Step 5**: Generate zarf.yaml and Create Zarf Package
   - Runs `generate_zarf_yaml.py` to create package definition
   - Runs `create_zarf_package.sh` to build package
   - Takes 10-30 minutes depending on asset size
   - Produces `dist/zarf-package-openCenter-airgap-*.tar.zst`

7. **Step 6**: Verify SBOM Generation
   - SBOM automatically generated by Zarf
   - Runs `verify_sbom.py` to check completeness
   - Ensures all components are listed in SBOM

8. **Step 7**: Generate Checksums
   - Runs `checksum_utils.py` to compute MD5 and SHA256
   - Saves checksums to `<package>.checksums` file

9. **Step 8**: Sign Package (Optional)
   - Runs `sign_package.sh` if `COSIGN_KEY` is set
   - Creates detached signature with Cosign
   - Skip with `--skip-signing`

### Command Line Options

```
--skip-download       Skip kubespray-offline asset download (use existing)
--skip-terraform      Skip Terraform provider collection
--skip-validation     Skip version validation
--skip-signing        Skip package signing (even if key available)
--openstack           Enable OpenStack mode (collect Terraform providers)
--help                Show help message
```

### Environment Variables

```
PYTHON_VERSION        Python version to use (default: 3.12)
COSIGN_KEY            Path to Cosign signing key (optional)
SKIP_ASSET_DOWNLOAD   Skip asset download if set to "true"
OPENSTACK_MODE        Enable OpenStack mode if set to "true"
```

### Output Artifacts

After successful build, the following artifacts are created in `dist/`:

- `zarf-package-openCenter-airgap-amd64-<version>.tar.zst` - Main package
- `zarf-package-openCenter-airgap-amd64-<version>.tar.zst.checksums` - MD5 and SHA256
- `zarf-package-openCenter-airgap-amd64-<version>.tar.zst.sig` - Cosign signature (if signed)
- `package-inspection.txt` - Package contents listing
- `package-sbom.txt` - Software Bill of Materials
- `sbom-verification-report.txt` - SBOM completeness report

### Troubleshooting

**Error: Python 3.12+ required**
- Install Python 3.12 or higher
- On Ubuntu: `sudo apt install python3.12 python3.12-venv`

**Error: kubespray-offline not found**
- Clone kubespray-offline: `git clone -b main https://github.com/tmurakam/kubespray-offline.git build/kubespray-offline`

**Error: Zarf CLI not found**
- Install Zarf: https://docs.zarf.dev/getting-started/install/

**Error: Insufficient disk space**
- Free up at least 50GB of disk space
- Check with: `df -h .`

**Error: Package size exceeds limit**
- Review asset list in `config/versions.env`
- Remove unnecessary images from `build/kubespray-offline/imagelists/additional_images.txt`

**Error: Version validation failed**
- Review violations in output
- Pin all versions in configuration files
- No "latest", "stable", or wildcard versions allowed

## Individual Scripts

### organize_assets_for_zarf.sh
Organizes kubespray-offline outputs into Zarf-compatible structure.

### version_validator.py
Validates that all versions are pinned (no "latest", "stable", wildcards).

### generate_zarf_yaml.py
Generates `zarf.yaml` package definition from asset inventory.

### create_zarf_package.sh
Creates Zarf package and verifies contents.

### checksum_utils.py
Calculates MD5 and SHA256 checksums for files.

### sign_package.sh
Signs package with Cosign for cryptographic verification.

### verify_sbom.py
Verifies SBOM completeness and accuracy.

### mirror_terraform_providers.sh
Downloads Terraform providers for offline use (OpenStack mode).

## Build Time Estimates

- Asset collection (Step 1): 30-60 minutes
- Asset organization (Step 2): 2-5 minutes
- Terraform providers (Step 3): 5-10 minutes (if enabled)
- Version validation (Step 4): < 1 minute
- Package creation (Step 5): 10-30 minutes
- SBOM verification (Step 6): < 1 minute
- Checksum generation (Step 7): 1-5 minutes
- Package signing (Step 8): < 1 minute

**Total build time**: 45-90 minutes (first build with asset download)
**Rebuild time**: 15-40 minutes (with `--skip-download`)

## Disk Space Requirements

- kubespray-offline outputs: ~20GB
- Organized assets: ~25GB
- Zarf package: ~8-10GB
- Build artifacts: ~2GB
- **Total required**: ~50GB free space
