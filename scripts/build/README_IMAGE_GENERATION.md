# Image List Generation

## Overview

Image lists are generated by scanning multiple sources:

1. **kubespray repository** - Kubernetes core images from manifests
2. **kubespray-offline outputs** - Downloaded images after running download-all.sh
3. **gitops-base repository** - openCenter platform service images

## Performance

Typical scan duration:
- Small repos (<100 files): 5-15 seconds
- Medium repos (100-1000 files): 15-60 seconds
- Large repos (>1000 files): 1-5 minutes
- Full scan (all 4 repos): 2-10 minutes depending on repo sizes

Factors affecting performance:
- Number of files in repositories
- File sizes (large YAML files take longer to parse)
- Disk I/O speed
- CPU performance for regex matching


## Generated Files

```
config/
├── kubespray-images.txt           # Scanned from kubespray repo
├── kubespray-offline-images.txt   # Extracted from kubespray-offline outputs
├── opencenter-images.txt          # Scanned from gitops-base
└── all-images.txt                 # Combined deduplicated list
```

## Usage

### Full Regeneration

```bash
./scripts/build/generate_image_lists.sh
```

This will:
1. Scan all repositories for image references
2. Extract images from kubespray-offline outputs (if available)
3. Consolidate into separate lists
4. Generate combined master list

### Prerequisites

```bash
# Clone required repositories
git clone https://github.com/rackerlabs/genestack.git assets/gitops-base
git clone https://github.com/kubespray-offline/kubespray-offline.git build/kubespray-offline

# Optional: Clone kubespray for direct scanning
git clone https://github.com/kubernetes-sigs/kubespray.git assets/kubespray/kubespray-master
```

### After kubespray-offline Download

```bash
# Run kubespray-offline first
cd build/kubespray-offline
./download-all.sh

# Then regenerate lists to include downloaded images
cd ../..
./scripts/build/generate_image_lists.sh
```

## Scan Details

Detailed scan results are saved to `build/repository-scans/`:

```
build/repository-scans/
├── kubespray-images.txt
├── kubespray-scan-details.json
├── gitops-base-images.txt
├── gitops-base-scan-details.json
├── all-repositories-images.txt
└── all-repositories-urls.txt
```

JSON files contain source file locations for each discovered image/URL.

## Image Pattern Detection

The scanner detects:

- Full registry format: `registry.io/repo/image:tag`
- Docker Hub shorthand: `repo/image:tag`
- YAML image fields: `image: repo/image:tag`
- Helm repository fields: `repository: registry.io/repo/image`

## URL Detection

Also extracts HTTP/HTTPS URLs for:
- Binary downloads
- GitHub releases
- Documentation references
- External dependencies

## Integration with Zarf

```bash
# Update zarf.yaml images block

python3 scripts/build/build.py
```

## Troubleshooting

### No images found

- Ensure repositories are cloned to correct locations
- Check that gitops-base contains Helm charts/manifests
- Verify file permissions allow reading

### Missing kubespray-offline images

- Run `kubespray-offline/download-all.sh` first
- Check `build/kubespray-offline/outputs/` exists
- Re-run `generate_image_lists.sh`

### Duplicate images

- Normal - scanner deduplicates automatically
- Check `all-images.txt` for final deduplicated list

## Manual Verification

```bash
# Count images per source
grep -v '^#' config/kubespray-images.txt | grep -v '^$' | wc -l
grep -v '^#' config/opencenter-images.txt | grep -v '^$' | wc -l
grep -v '^#' config/all-images.txt | grep -v '^$' | wc -l

# Find specific image
grep -r "prometheus" config/*-images.txt

# Compare with Zarf package
zarf package inspect dist/zarf-package-*.tar.zst --list-images > /tmp/zarf-images.txt
diff <(sort config/all-images.txt) <(sort /tmp/zarf-images.txt)
```
